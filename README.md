# 💕 Dedicatorias Románticas para tu Esposa

Un hermoso repertorio de código HTML dedicatoria romantica.

Un proyecto dedicado a expresar los sentimientos más profundos hacia la persona que amas. Cada dedicatoria es un mensaje del corazón, creado con códigos que representan la belleza de nuestro amor.

## ✨ Características

- 🎨 Diseño elegante y romántico
- 💻 Código HTML, CSS y JavaScript limpio
- 📱 Interfaz responsiva
- 🎭 Animaciones atractivas
- 💝 Fácil de personalizar
- 🌐 Listo para implementar

## 📁 Estructura del Proyecto

```
├── index.html          # Página principal
├── css/
│   └── styles.css      # Estilos del proyecto
├── js/
│   ├── script.js       # Funcionalidades interactivas
│   └── carousel.js     # Carrusel de imágenes
├── .gitignore          # Archivos ignorados
└── README.md           # Este archivo
```

## 🚀 Cómo Usar

1. **Clonar el repositorio**
   ```bash
   git clone https://github.com/bcaizales-design/Dedicatorias-rom-nticas-esposa-.git
   cd Dedicatorias-rom-nticas-esposa-
   ```

2. **Abrir en el navegador**
   - Simplemente abre el archivo `index.html` en tu navegador favorito

3. **Personalizar**
   - Edita el contenido en `index.html`
   - Modifica los estilos en `css/styles.css`
   - Añade funcionalidades en `js/script.js`

## 🎯 Tecnologías Utilizadas

- **HTML5** - Estructura semántica
- **CSS3** - Diseño y animaciones
- **JavaScript** - Interactividad y efectos dinámicos
